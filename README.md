# Azure Administration Lab Portfolio

This repository documents hands-on Azure administration labs completed in a personally owned, non-production environment while preparing for the Microsoft Certified: Azure Administrator Associate (AZ-104) certification.

The purpose of this portfolio is to demonstrate practical experience with Azure identity management, governance, networking, compute, storage, monitoring, security principles, and administrative documentation.

## Professional Objective

I am a cleared Systems Administrator and Information System Security Officer with active-duty U.S. Navy IT experience in Microsoft 365, Microsoft Entra ID, Active Directory, Windows Server, endpoint administration, access control, and cybersecurity compliance.

I am using this portfolio to expand my Azure and cloud-administration skills through structured, hands-on lab work.

## Technical Focus Areas

- Microsoft Entra ID identity administration
- Azure subscriptions and role-based access control
- Azure Policy and governance
- Azure Resource Manager templates
- Virtual networks, subnets, and Network Security Groups
- Intersite connectivity and network traffic management
- Azure Storage
- Azure Virtual Machines
- Azure App Services and container services
- Azure Backup and data protection
- Azure Monitor, alerts, and resource monitoring
- PowerShell automation and administrative reporting
